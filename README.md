# Portfólio Web — Gabriel Moreira Lima

## Sobre o projeto

Este projeto é um portfólio pessoal desenvolvido durante o curso de Desenvolvimento de Sistemas. Seu objetivo é apresentar minha trajetória acadêmica, meus conhecimentos, cursos, palestras e certificados, reunindo minhas principais experiências em um único lugar.

O site foi desenvolvido utilizando HTML5, CSS3, JavaScript e Bootstrap, buscando uma aparência profissional, organizada e responsiva.

## Acesse o projeto

- **Site publicado:** https://portgabrielgg-omega.vercel.app/
- **Repositório GitHub:** https://github.com/Biellzyl/port.gabrielgg

## Tecnologias utilizadas

- HTML5 — estruturação das páginas.
- CSS3 — estilização e identidade visual.
- JavaScript — funcionalidades e interatividade.
- Bootstrap 5.3.3 — componentes e responsividade.
